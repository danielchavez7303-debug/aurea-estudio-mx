# ÁUREA — Arquitectura & Interiores

Landing page editorial para un estudio conceptual de arquitectura e interiorismo en Guadalajara.

## Desarrollo

```bash
npm install
npm run dev
```

El proyecto usa Vinext/Vite y exportación estática para Cloudflare Pages.

Publicado en Cloudflare Pages: https://aurea-estudio-mx.pages.dev

## Estado

Proyecto conceptual de portafolio; todos los datos, proyectos y testimonios son ficticios.
